# 小红书下载器 (Android 版)

使用 Kotlin、Jetpack Compose 和 miuix 构建的 Android 小红书笔记下载工具，支持图片、视频、实况照片与笔记文案保存。

## 主要功能

- **图片与视频下载**：解析笔记中的媒体资源并获取其原始文件 cdn 地址，支持预览后选择部分内容下载，以及保存视频封面。
- **评论配图下载**：在「设置 → 媒体与格式」开启后，可保存笔记数据中已加载的评论与回复图片，也可在选择下载中单独勾选。尚未加载的评论不会自动翻页获取，可在内置浏览器中加载后重新提取。
- **实况照片保存**：支持按设备自动选择或手动指定通用、小米、OPPO、三星格式，以及实验性的 vivo 单/双文件、华为/荣耀格式；也可分别保存图片与视频，或仅保存静态图片。厂商相册识别仍需真机验证。
- **文案与笔记信息**：提取文案并复制到剪贴板，将笔记信息保存为 TXT / Markdown，也可仅保存信息而不下载媒体。
- **任务队列**：支持多个笔记链接、后台下载、暂停、继续、取消和失败重试；显示进度与实时下载速度，部分失败时保留已成功的资源。
- **媒体偏好**：可选原始图片格式或 JPEG、PNG、WebP、HEIC、AVIF；视频支持分辨率、码率、文件大小及 H.264 兼容性优先策略。
- **文件归档**：支持自选存储目录、命名模板、按作者或笔记分目录、作者备注，以及写入笔记发布时间。
- **记录管理**：搜索和筛选历史任务，长按卡片复制链接或删除记录；支持智能跳过已保存媒体，导出 JSON / CSV 资源记录。
- **网页提取与会话**：针对不支持 okhttp 方式获取内容的笔记，可选从内置 webview 爬取内容；可配置手动 Cookie、超时、重试及 HTTP / SOCKS5 代理。

## 使用说明

### 下载笔记

1. 在小红书 App 中复制笔记分享内容或链接，也可通过系统分享发送给本应用。
2. 回到应用，点击首页的剪贴板下载按钮；开启「手动输入链接」后，可在输入框中粘贴分享内容或多个笔记链接。
3. 如需挑选图片或视频，使用选择下载功能，预览并勾选需要的内容后提交。
4. 在任务卡片中查看进度、网速和结果，或暂停、继续、取消及重试任务。下载完成后可在应用内预览，或前往系统相册、文件管理器查看。

首页更多菜单提供「提取文案」「从网页爬取」「仅保存笔记信息」入口，均可手动输入链接。

### 网页账号登录

点击设置顶部的「小红书账号」，在内置浏览器中完成登录。登录会话保存在本机，返回后显示昵称和头像，并可供网页提取及开启「复用网页会话」的新下载任务使用。浏览器采用桌面 UA，支持缩放；Chrome 与应用内浏览器的登录状态不互通。

### 设置与保存位置

- **媒体与格式**：调整图片格式、视频优先级、封面及实况照片保存方式。
- **归档与记录**：配置作者 / 笔记目录、作者备注、笔记信息格式、智能跳过及记录导出。
- **网络与会话**：调整超时、重试和代理，使用内置浏览器登录，或配置手动会话。手动 Cookie 仅在本机加密保存，不参与记录导出。

默认图片保存到 `Pictures/xhsdn`，视频保存到 `Movies/xhsdn`，笔记信息保存到 `Download/xhsdn`。也可选择内部存储或 SD 卡上的本地文件夹；启用归档后会在保存位置下创建对应子目录。

设置变更仅用于新任务，已有任务保留提交时的配置。智能跳过默认关闭；开启后，仅在资源记录匹配且文件仍可访问时跳过。

### 支持的链接

支持分享文本中的小红书 / RedNote 笔记链接，以及指向笔记的短链接，例如：

- `https://www.xiaohongshu.com/explore/...`
- `https://www.xiaohongshu.com/discovery/item/...`
- `https://www.rednote.com/explore/...`
- `https://xhslink.com/...`
- `https://xhslink.cn/...`

**多个笔记链接可分别建立下载任务，但目前不支持通过个人主页、收藏或专辑链接自动采集并批量下载全部笔记。** 指向个人主页的短链接也不属于可下载笔记链接。

## 常见问题

### 解析或下载失败怎么办？

先确认分享链接指向具体笔记，且笔记仍可访问。可尝试「从网页爬取」，在内置浏览器中打开笔记，必要时登录后再提取。网络异常可重试任务；内容被删除、访问受限或平台接口变化时，仍可能无法下载。

### 指定的图片格式或视频画质为什么没有生效？

图片格式取决于服务器实际提供的资源；指定格式不可用时，会按实际返回格式保存并提示。视频默认优先尝试原始资源，再按所选策略尝试其他规格；H.264 兼容模式不执行本地转码，也不保证每条笔记都提供对应编码。

### 实况照片为什么无法播放？

动态照片的识别取决于设备和相册应用，可在「设置 → 媒体与格式 → 实况合成格式」切换目标格式（新建任务生效），或选择图片与视频分别保存。格式差异、开源参考和验证边界见 [实况兼容性说明](docs/LIVE_PHOTO_COMPATIBILITY.md)。合成失败时应用会保留可用的原始组件；若部分组件下载失败，任务会明确提示。

### 为什么相册里找不到文件？

自定义目录是否立即出现在第三方相册中取决于系统索引。可先通过应用内预览或文件管理器查看；TXT / Markdown 笔记信息不显示在相册中。写入发布时间也受系统及存储提供方支持情况限制。

### 退出应用后，任务会继续吗？

下载通过前台服务在后台运行；系统终止进程或应用重新启动后，未完成任务会保留并暂停，需要手动继续。断点续传取决于服务器是否支持且资源仍有效，无法续传时会重新获取相应资源。

### 如何更新？

启动应用时会自动检查 GitHub 上的正式版本，检查失败或无需更新时不打扰。也可在「设置 → 检查更新」中查看结果；发现新版后点击「前往下载」打开 Release 页面，自行下载并安装 APK。
